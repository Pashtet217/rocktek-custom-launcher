# Сборка APK через браузер — без установки программ на Windows

## Что потребуется
Бесплатный аккаунт GitHub. Android Studio, Java и Android SDK на компьютер устанавливать не нужно.

## Шаги
1. В браузере откройте https://github.com/ и войдите или зарегистрируйтесь.
2. Нажмите `+` → `New repository`.
3. Название: `rocktek-custom-launcher`. Выберите `Public` (так проще использовать бесплатные GitHub Actions), затем `Create repository`.
4. На странице репозитория нажмите `Add file` → `Upload files`.
5. Распакуйте архив проекта на компьютере и перетащите в окно GitHub все файлы и папки проекта, включая `app`, `gradle` (если есть), файлы `*.kts`, `gradle.properties`, README. Не загружайте ZIP как один файл.
6. Нажмите `Commit changes`.
7. В репозитории откройте вкладку `Actions`. Если workflow `Build RockTek Launcher APK` появился, откройте его и нажмите `Run workflow` → `Run workflow`.
8. Дождитесь зелёной галочки у запуска. Откройте его и внизу страницы найдите `Artifacts`.
9. Скачайте `RockTek-Custom-Launcher-1.0-APK.zip`, распакуйте его. Внутри будет `app-debug.apk`.

## Важно про папку workflow
GitHub Actions должен получить файл `.github/workflows/build-apk.yml`.
При загрузке через веб-интерфейс скрытая папка `.github` может не попасть в загрузку. Если после загрузки вкладка Actions не показывает workflow:
- в репозитории нажмите `Add file` → `Create new file`;
- имя файла укажите точно: `.github/workflows/build-apk.yml`;
- откройте локальный файл `.github/workflows/build-apk.yml` из распакованного архива, скопируйте весь текст и вставьте в редактор GitHub;
- нажмите `Commit changes`.

Сборка создаёт отладочный APK (debug), а не подписанный релизный APK. Его можно установить вручную на собственную приставку, разрешив установку из неизвестного источника для приложения, через которое открываете файл.

## Ограничения
Проект пока не проверен на физическом RockTek G2. Даже если облачная сборка завершится успешно, перед выбором новым лаунчером по умолчанию нужно проверить его работу, оставив Projectivy установленным.
