# RockTek Custom Launcher 1.0

Исходный проект Android TV-лаунчера для RockTek G2.

## Возможности версии 1.0
- HOME launcher для Android TV.
- Список установленных приложений с запуском с пульта.
- Категории: Избранное, Все, ТВ и видео, Музыка, Система.
- Удержание OK на плитке добавляет/удаляет приложение из избранного.
- Выбор собственных обоев с сохранением доступа к изображению после перезапуска.
- Часы и погода Open-Meteo (без API-ключа); город задаётся вручную.
- Projectivy не удаляется и может оставаться резервным лаунчером.

## Сборка APK
1. Откройте папку проекта в Android Studio (актуальная версия).
2. Дождитесь синхронизации Gradle.
3. Выберите Build → Build Bundle(s) / APK(s) → Build APK(s).
4. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

Требования: JDK 17, Android SDK Platform 35, Android Gradle Plugin 8.7.3.

## Установка
Скопируйте APK на RockTek G2 и установите его. При нажатии HOME Android должен предложить выбрать главный экран. Выберите RockTek Custom Launcher. Projectivy оставьте установленным.

Чтобы вернуться к Projectivy: Настройки Android → Приложения → Приложения по умолчанию → Главный экран (название пунктов зависит от прошивки).

## Ограничения прототипа
- Это исходный проект, не готовый проверенный APK. Сборка и проверка на RockTek G2 ещё не выполнялись.
- Категории ТВ/видео, Музыка и Система определяются по названию/пакету приложения; некоторые приложения могут попасть не в ту категорию.
- Погода загружается при запуске и после смены города; для неё нужен интернет.
- На разных прошивках Android TV доступность выбора HOME launcher может отличаться.
- Приложения, которые не публикуют обычный LAUNCHER activity, могут не отображаться.
